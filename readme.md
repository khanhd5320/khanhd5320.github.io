# Đám cưới Quốc Khánh ❤️ Minh Anh

Website thiệp cưới online cho đám cưới của Quốc Khánh và Minh Anh.

## Giới thiệu

Website thiệp cưới điện tử với giao diện đẹp mắt, hiệu ứng động và thông tin chi tiết về sự kiện cưới.

## Tính năng

- Giao diện responsive, tương thích mọi thiết bị
- Hiệu ứng animation mượt mà
- Hiển thị thông tin cô dâu - chú rể
- Album ảnh cưới
- Thông tin địa điểm và thời gian tổ chức
- Tích hợp Google Maps
- Thông tin tài khoản ngân hàng để mừng cưới

## Công nghệ sử dụng

- HTML5, CSS3, JavaScript
- Bootstrap 
- jQuery
- Font chữ: Be Vietnam Pro, Corinthia, Prata, Muli Display VN

## Cấu trúc thư mục

```
├── index.html          # Trang chính
├── css/                # File CSS
├── js/                 # File JavaScript
├── images/             # Hình ảnh
├── fonts/              # Font chữ
└── lib/                # Thư viện (Bootstrap, jQuery)
```

## Cài đặt

1. Clone hoặc tải project về máy
2. Mở file `index.html` bằng trình duyệt web

## Tùy chỉnh

Chỉnh sửa nội dung trong file `index.html` để cập nhật:
- Tên cô dâu - chú rể
- Thời gian và địa điểm
- Hình ảnh
- Thông tin ngân hàng
- Các thông tin khác
